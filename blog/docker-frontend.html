Docker 入门：前端开发者视角

2026-03-20 7 min read
Docker前端工程化

前端项目部署常遇到 Node 版本不一致、依赖装不上、环境变量遗漏等问题。Docker 把应用和运行环境打包成镜像，实现「一次构建，到处运行」。

核心概念

  • 镜像（Image）：只读模板，类似类
  • 容器（Container）：镜像的运行实例
  • Dockerfile：构建镜像的 recipe

多阶段构建：React / Vite 项目

# 阶段 1：构建
FROM node:20-alpine AS builder
WORKDIR /app
COPY package*.json ./
RUN npm ci
COPY . .
RUN npm run build

# 阶段 2：用 nginx 托管静态文件
FROM nginx:alpine
COPY --from=builder /app/dist /usr/share/nginx/html
EXPOSE 80
CMD ["nginx", "-g", "daemon off;"]

最终镜像只有 nginx + 静态资源，体积从 1GB+ 降到几十 MB。

常用命令

docker build -t my-app .
docker run -p 8080:80 my-app
docker ps                    # 查看运行中容器
docker logs <container_id>   # 查看日志

docker-compose 本地联调

前后端分离时，一个 compose 文件拉起 API + 前端 + 数据库：

services:
  web:
    build: ./frontend
    ports: ["3000:80"]
  api:
    build: ./backend
    ports: ["4000:4000"]
    environment:
      - DATABASE_URL=postgres://db:5432/app
  db:
    image: postgres:16-alpine

前端开发者何时需要 Docker

  • 团队统一开发环境（Node 版本、系统库）
  • CI/CD 流水线中 reproducible build
  • 预览环境一键部署
  • 全栈项目本地模拟生产架构
