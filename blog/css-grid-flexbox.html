CSS Grid 与 Flexbox：如何选择

Windy

4 min read

Flexbox 和 Grid 不是竞争关系，而是互补。一句话总结：一维用 Flex，二维用 Grid。

Flexbox：沿单轴排列

适合导航栏、按钮组、卡片内垂直居中、等分空间等场景。主轴（row/column）上灵活分配空间，交叉轴对齐简单。

CODE 
.nav {
  display: flex;
  justify-content: space-between;
  align-items: center;
  gap: 1rem;
}

Grid：行与列同时控制

适合页面整体布局、图片画廊、仪表盘、复杂表单。可以精确定义轨道、区域命名、跨行跨列。

CODE 
.layout {
  display: grid;
  grid-template-columns: 240px 1fr;
  grid-template-rows: auto 1fr auto;
  grid-template-areas:
    "sidebar header"
    "sidebar main"
    "sidebar footer";
  min-height: 100vh;
}

决策树

  • 内容决定尺寸，只需排成一行/一列 → Flex
  • 需要固定列宽、等高卡片、整体页面骨架 → Grid
  • 组件内部用 Flex，页面级用 Grid → 常见组合

Grid 的 fr 与 minmax

CODE 
.cards {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(280px, 1fr));
  gap: 1.5rem;
}

这一行实现响应式卡片网格：列宽不小于 280px，剩余空间等分，无需媒体查询断点。

Container Queries

当组件需要在不同容器宽度下改变布局，@container 比 viewport 媒体查询更精准。Grid 定义骨架，Container Query 做组件级响应式，是 2024+ 的推荐模式。

不要问「哪个更好」，问「我要控制几个维度」。一维 Flex，二维 Grid，组合使用才是正道。
