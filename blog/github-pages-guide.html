GitHub Pages 静态站点部署指南

2026-04-15 5 min read
DevOpsGitHub

GitHub Pages 让静态网站免费托管在 GitHub 上，推送代码即自动发布。本文以纯 HTML 站点为例，走通完整流程。

两种 URL 形式

  • 用户/组织站：仓库名必须为 username.github.io，访问 https://username.github.io
  • 项目站：任意仓库名，访问 https://username.github.io/repo-name/

本站在 windy.github.io 仓库，属于项目站，路径需注意相对链接。

启用 Pages

  1. 仓库 Settings → Pages
  2. Source 选 Deploy from a branch
  3. Branch 选 main，目录选 / (root)
  4. 保存后等待构建，绿色勾即部署成功

目录结构

windy.github.io/
├── index.html      # 首页（必须有）
├── css/
├── js/
└── blog/           # 文章子目录

根目录的 index.html 会作为站点入口。仅 README 时 GitHub 会渲染 Markdown，但自定义 HTML 体验更好。

自定义域名（可选）

在 Pages 设置里填域名，并在 DNS 添加 CNAME 记录指向 username.github.io。仓库根目录放 CNAME 文件写入域名，防止被覆盖。

GitHub Actions 自动部署

若使用 Vite / Next 静态导出，可用 Actions 构建后推送到 gh-pages 分支：

name: Deploy
on:
  push:
    branches: [main]
jobs:
  deploy:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - run: npm ci && npm run build
      - uses: peaceiris/actions-gh-pages@v4
        with:
          github_token: ${{ secrets.GITHUB_TOKEN }}
          publish_dir: ./dist
纯静态站最简单：main 分支 + index.html，push 即上线，零服务器成本。
