Cursor 使用半年的观察

Windy

8 min read

从 2025 年底开始，Cursor 成为我的主力 IDE。半年下来，它已经从「有趣的实验工具」变成了日常开发不可或缺的一部分。以下是一些真实的使用观察。

什么场景最有效

  • 探索陌生代码库：让 Agent 快速定位关键文件和调用链
  • 重复性重构：批量重命名、提取函数、统一代码风格
  • 测试编写：根据现有代码生成单元测试框架
  • 文档同步：代码变更后自动更新 README 和相关文档

什么场景仍需人工

架构决策、复杂业务逻辑的设计、以及涉及多个系统的集成调试——这些仍然需要人类的判断力和领域知识。Agent 可以加速执行，但不能替代思考。

工作流建议

  1. 将大任务拆分为小步骤，逐步交给 Agent
  2. 每次变更后立即 review diff，不要累积
  3. 善用 Rules 和 Skills 固化项目约定
  4. 保持 git commit 粒度小，方便回滚
最好的 AI 工作流不是完全自动化，而是人机协作的最优分工。

Cursor 还在快速迭代中。Agent 模式、Background Tasks、MCP 集成都还在进化。作为早期使用者，我的建议是：保持开放，但保持批判性思维。
