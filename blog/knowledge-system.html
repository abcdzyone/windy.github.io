我的知识管理体系

2026.05.01 7 min read
PKMObsidian

知识管理（PKM）不是囤积信息，而是建立从输入到输出的可持续系统。经过一年多的迭代，我形成了一套基于 Obsidian + Git 的个人知识管理体系。

核心原则

  • 单一入口：所有笔记写入 Obsidian vault
  • 版本控制：vault 通过 Git 同步，保留完整历史
  • 双向链接：笔记之间建立语义关联，而非文件夹层级
  • 定期回顾：每周 review inbox，每月整理标签和 MOC

PARA 结构

采用 Tiago Forte 的 PARA 方法论组织顶层目录：

  • Projects：有明确截止日期的工作
  • Areas：需要持续维护的责任领域
  • Resources：未来可能有用的参考资料
  • Archives：已完成或不再活跃的内容

输入 → 输出链路

阅读时使用渐进式摘要（Progressive Summarization）：高亮 → 加粗 → 用自己的话总结 → 写连接笔记。最终输出形式包括技术博客、项目文档、以及这个 Digital Archive 网站本身。

知识管理的价值不在于存储了多少，而在于连接了多少、输出了多少。

系统还在持续优化中。下一步计划引入 AI 辅助的笔记检索和自动 tagging，让知识库真正「活」起来。
