# Windy · Personal Site

个人开发者主页，部署于 GitHub Pages。

**在线预览：** https://abcdzyone.github.io/windy.github.io/

## 特性

- 粒子网络 Canvas 背景 + 鼠标交互
- 打字机效果 Hero 区
- 玻璃拟态卡片 + 滚动入场动画
- 技能进度条 + 技术栈跑马灯
- 响应式布局，移动端友好

## 本地预览

直接用浏览器打开 `index.html`，或：

```bash
npx serve .
```
