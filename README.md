# Windy · Personal Site

个人开发者主页 + 技术博客，部署于 GitHub Pages。

**在线预览：** https://abcdzyone.github.io/windy.github.io/

## 特性

- 苹果系统字体（SF Pro / PingFang SC）
- 粒子 Canvas 背景 + 滚动动画
- 6 篇模拟技术文章（JavaScript / TS / Docker / CSS / Git / GitHub Pages）
- 无 emoji，极简深色风格

## 结构

```
├── index.html
├── css/style.css, blog.css
├── js/main.js
└── blog/*.html
```
